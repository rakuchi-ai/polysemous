# GMARCH英語 4択小テスト Webアプリ

GMARCHレベルの英語必修単語（多義語・派生語）を4択クイズ形式で演習できるWebアプリケーションです。

## 特長・機能
- **出題範囲の選択**: 「すべて」「多義語」「派生語」から選択可能
- **問題数の設定**: 5問、10問、20問、30問、全問から選択可能
- **ミス問題の自動保存（ストック機能）**: 不正解になった問題をブラウザ（LocalStorage）に自動保存し、いつでも復習・やり直しが可能
- **GitHub Pages完全対応**: サーバー不要でブラウザのみで動作

## GitHub Pagesでの公開手順
1. ダウンロードしたZIPファイルを解凍し、中身の `index.html` と `README.md` をGitHubリポジトリにアップロード（コミット）します。
2. リポジトリの **Settings** ➔ **Pages** に移動します。
3. **Branch** を `main` (または `master`) に設定し、**Save** をクリックします。
4. 数分後に発行されるURLからアクセスすると、Webアプリとして利用できます。
